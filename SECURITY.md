# Security

## Supported versions

This package is below 1.0. Only the latest version on npm gets security fixes; a fix comes in a new release, never in an older one.

| Version | Supported |
|---|---|
| latest release | yes |
| anything older | no |

## Reporting a vulnerability

Please do not open a public issue. Report it privately on GitHub: in this repository's **Security** tab, choose **Report a vulnerability** ([direct link](https://github.com/stefanocaronia/rpg-engine-lockpicking/security/advisories/new)). Say what you found, how to reproduce it, and what it lets someone do.

A problem in RPG Engine itself, or in how it installs and runs packages, goes to [RPG Engine's repository](https://github.com/stefanocaronia/rpg-engine/security/advisories/new).

## What to expect

This package is made by one person, in their own time. Your report will be read and answered as soon as that person can: there is no fixed response time, and no bug bounty. When a report is confirmed, the fix is released and a GitHub security advisory published, crediting you if you wish. Please keep the details private until then; we will agree a date with you.

## By design, not a vulnerability

This package is code: it runs on your computer with your permissions, as any npm package does; the rest is in [RPG Engine's security policy](https://github.com/stefanocaronia/rpg-engine/blob/main/SECURITY.md).
